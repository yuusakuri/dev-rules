# 画面設計書作成ガイドライン

## 1 はじめに

### 1.1 目的

この文書の目的は、画面の設計者及び実装者が、画面上の配置及び各項目の属性を同じ定義に基づいて扱えるようにすることである。

### 1.2 適用範囲

この文書は、UI仕様書に対応する画面設計書の作成方法について規定する。画面のレイアウト区画、表示項目、入力項目及び操作要素の遷移先を扱う。

## 2 UI仕様書との分担

画面設計書には、画面上の配置及び項目の属性を記載する。操作に対する状態の変化及び判定は、UI仕様書の定義を参照する。両文書で同じ対象の識別子を使用し、対応する定義を追跡可能にする。

記載先の分担は、[表1](#table-1)による。

<a id="table-1"></a>表1−画面設計書及びUI仕様書の記載先

| 記載する内容 | 記載先 | 他方の文書からの参照方法 |
| --- | --- | --- |
| レイアウト区画 | 画面設計書 | 区画の識別子で参照する。 |
| 表示項目及び入力項目の属性 | 画面設計書 | 項目の識別子で参照する。 |
| 項目の初期値及び取得元 | 画面設計書 | 項目の識別子で参照する。 |
| 操作要素の代表的な遷移先 | 画面設計書 | 操作要素と遷移先との対応を参照する。 |
| 状態遷移、入力検証、権限制御及びエラー処理 | UI仕様書 | 状態又は操作の定義を参照する。 |

## 3 識別子

画面の識別子は、UI仕様書の識別子と一致させる。入力項目の識別子も両文書で一致させ、同じ対象への参照を維持する。

画面、区画及び項目の識別子は、[表2](#table-2)による。`<SCREEN>`は、画面の識別子から`SCR-`を除いた部分を表す。

<a id="table-2"></a>表2−画面、区画及び項目の識別子

| 対象 | 形式 | 例 |
| --- | --- | --- |
| 画面 | `SCR-<DOMAIN>-<NNN>` | `SCR-USER-001` |
| レイアウト区画 | `RGN-<SCREEN>-<NAME>` | `RGN-USER-001-HEADER` |
| 表示項目 | `DSP-<SCREEN>-<NNN>` | `DSP-USER-001-003` |
| 入力項目 | `FLD-<SCREEN>-<NNN>` | `FLD-USER-001-003` |

## 4 ファイル及び文書情報

### 4.1 配置

画面設計書は、対応するUI仕様書と同じディレクトリに、別のファイルとして配置する。配置は、[表3](#table-3)による。

<a id="table-3"></a>表3−画面ごとの文書の配置

| パス | 内容 |
| --- | --- |
| `docs/specifications/ui/screens/<screen-id>-<name>.md` | 画面のUI仕様を記載する。 |
| `docs/specifications/ui/screens/<screen-id>-<name>.design.md` | 画面の配置及び項目を記載する。 |

### 4.2 文書情報

文書の名称の直後に、文書番号、版、ステータス及び責任者を表で記載する。発行者がある場合は、同じ表に記載する。

文書の版ごとの記録は、末尾の変更履歴に、版、日付及び変更内容を列とする表で記載する。

## 5 レイアウト区画

画面を役割ごとの区画に分け、区画ごとに識別子を付ける。区画の位置、並び順及び入れ子関係は、ワイヤーフレーム又はデザインファイルへのリンクで示す。

区画の定義例は、[表4](#table-4)による。寸法及び余白の数値は、リンク先のデザインファイルで管理する。

<a id="table-4"></a>表4−レイアウト区画の定義例

| 区画 | 役割 |
| --- | --- |
| `RGN-USER-001-HEADER` | 画面の題名及び主要な操作ボタンを配置する。 |
| `RGN-USER-001-FILTER` | 一覧を絞り込む入力項目を配置する。 |
| `RGN-USER-001-LIST` | 一覧を表示する。 |

## 6 表示項目

表示項目には、[表5](#table-5)の属性を記載する。表示の判定に状態遷移又は権限制御が関係する場合は、対応するUI仕様の定義を参照する。

<a id="table-5"></a>表5−表示項目の属性

| 属性 | 記載内容 |
| --- | --- |
| 識別子 | `DSP-<SCREEN>-<NNN>`の形式で記載する。 |
| 項目名 | 画面上のラベル又は項目の呼称を記載する。 |
| 配置区画 | 項目が属する区画の識別子を記載する。 |
| データ型 | 文字列、数値、日時、真偽値又は列挙値のように、値の種類を記載する。 |
| 取得元 | API、画面内の状態又はURLパラメーターのように、値を取得する場所を記載する。 |
| 初期値 | 取得前及びデータがない場合に表示する値を記載する。 |
| 表示条件 | 常に表示するか、指定した状態で表示するかを記載する。 |
| 表示形式 | 日付又は数値の書式を記載するか、UI仕様書の表示形式を参照する。 |

例えば、最終ログイン日時の項目には、取得元のAPI、日時の書式及びログイン履歴がない場合の表示値“未ログイン”を記載する。

## 7 入力項目

入力項目には、[表6](#table-6)の属性を記載する。項目間の関係を用いた入力検証、業務上の判定及び検証エラーの表示は、UI仕様書の定義を参照する。

<a id="table-6"></a>表6−入力項目の属性

| 属性 | 記載内容 |
| --- | --- |
| 識別子 | UI仕様書と同じ`FLD-<SCREEN>-<NNN>`を記載する。 |
| 項目名 | ラベルの文言を記載する。 |
| 配置区画 | 項目が属する区画の識別子を記載する。 |
| データ型 | 入力する値の種類を記載する。 |
| 桁数及び形式 | 最大文字数、数値の範囲及び正規表現のうち、適用する制約を記載する。 |
| 必須又は任意 | 入力の要否を記載する。 |
| 初期値 | 新規作成及び編集のそれぞれで設定する値を記載する。 |
| 入力部品 | テキスト欄、選択欄又は日付選択のように、入力に使用する部品を記載する。 |

## 8 操作要素の遷移先

ボタン及びリンクには、遷移先又は実行結果を記載する。成功又は失敗によって遷移先が異なる場合は、UI仕様書の状態遷移表を参照する。

操作要素の記載例は、[表7](#table-7)による。

<a id="table-7"></a>表7−操作要素の遷移先の記載例

| 操作 | 種別 | 遷移先又は実行結果 |
| --- | --- | --- |
| 新規作成ボタンを押す。 | 画面遷移 | `SCR-USER-002`のユーザー作成画面を開く。 |
| 一覧の行を選択する。 | 画面遷移 | `SCR-USER-003`のユーザー詳細画面を開く。 |
| CSVエクスポートを選択する。 | ファイル生成 | 一覧に表示中の内容をCSVファイルで取得する。 |

## 9 画面設計書の構成

画面設計書は、[表8](#table-8)の順に構成する。表示項目、入力項目又は操作要素がない場合は、その章に対象がない旨を記載する。

<a id="table-8"></a>表8−画面設計書の構成

| 構成要素 | 記載内容 |
| --- | --- |
| 名称及び文書情報 | 画面名、画面の識別子及び文書情報を記載する。 |
| 1 はじめに | 想定する読者及び文書の目的を記載する。概要を設ける場合は、画面の内容を1文で要約する。 |
| 2 レイアウト区画 | 区画の定義及びデザインファイルへのリンクを記載する。 |
| 3 表示項目 | 表示項目の属性を記載する。 |
| 4 入力項目 | 入力項目の属性を記載する。 |
| 5 操作要素の遷移先 | 操作要素の遷移先又は実行結果を記載する。 |
| 参考文献 | 参照した資料がある場合に、章との対応を記載する。 |
| 変更履歴 | 版ごとの日付及び変更内容を記載する。 |
