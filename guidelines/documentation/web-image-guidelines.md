# Webページからの画像取得ガイドライン

## 1 はじめに

### 1.1 目的

このガイドラインの目的は，Webページの図を，元の品質を保ったまま文書で再利用できるようにすることである。

### 1.2 適用範囲

このガイドラインは，Webページに掲載された図を取得する場合に適用する。

## 2 取得方針

Webページから図を取得する場合は，提供元が配布する画像ファイルを取得する。SVGがある場合はSVGを正本とする。

ページのスクリーンショットを原本として扱ってはならない。

ラスター画像は，元の解像度を保持する。低解像度の画像を拡大して高精細な図として扱ってはならない。
