# MarkdownからDOCXへの変換ガイドライン

## 1 はじめに

### 1.1 目的

このガイドラインの目的は，MarkdownからDOCXを生成する担当者が，本文，書式及び参照の対応を維持することである。

### 1.2 適用範囲

このガイドラインは，Markdownを正本とし，編集可能なDOCXを配布用成果物として生成する場合に適用する。Googleドキュメント形式へ変換する場合も対象とする。

## 2 正本と生成方法

本文はMarkdownで修正し，DOCXを再生成する。Googleドキュメントを配布する場合も，Markdownを修正してからDOCXとGoogleドキュメントを再生成する。

変換に使うプログラム，依存パッケージの版及び実行コマンドをリポジトリに記録する。生成したDOCXのファイル名は，対応するMarkdownと同じ基底名にする。

## 3 文書要素

見出しは見出しスタイル，表は編集可能な表，画像は埋め込み画像として出力する。箇条書き，強調，外部リンク及び脚注を含む文書では，各要素と参照番号をDOCXにも保持する。Markdownの画像に代替テキストがある場合は，DOCXの画像にも設定する。

Markdownの内部リンクは，変換前に参照先の存在を検査する。DOCXでも本文からの移動を必要とする場合は，内部ハイパーリンクを設定する。Googleドキュメントへ取り込むDOCXで図表のブックマークアイコンを避ける場合は，図表への本文参照を通常の文字として出力し，目次には見出しスタイルから生成する目次フィールドを用いる。Markdownのアンカーとリンクは保持する。

書式の指定がない場合，本文と見出しにはArial，コードにはRoboto Monoを用いる。各要素の文字サイズを[表1](#table-1)に示す。見出しには文字サイズだけでなく見出しスタイルを設定する。見出し4以降を使用する文書では，使用する各階層の文字サイズをその文書の書式定義に追加する。日本語を含む文書では，表示された日本語の書体を確認する。

<a id="table-1"></a>表1−DOCXの文字サイズ

| 要素 | 文字サイズ |
| --- | ---: |
| タイトル | 26 pt |
| サブタイトル | 15 pt |
| 見出し1 | 20 pt |
| 見出し2 | 16 pt |
| 見出し3 | 14 pt |
| 通常のテキスト | 11 pt |
| インラインコード | 11 pt |
| コードブロック | 9 pt |

## 4 確認

生成後に，MarkdownとDOCXの見出し，表，画像，箇条書き，強調，外部リンク及び脚注の件数と内容を照合する。画像の代替テキストも照合する。内部リンクを出力する場合は，リンクの件数と移動先を確認する。本文参照を通常の文字に変換する場合は，意図しない内部リンクやブックマークが残っていないことを確認する。ページ表示で表の分断，画像の欠落，文字の重なり及び欠字を確認する。

Googleドキュメントへ取り込む場合はGoogleドキュメント形式へ変換し，DOCXと同じ文書要素，書式及び画像の代替テキストを照合する。目次が見出しへ移動できることを文書画面で確認する。取り込んだ目次が移動できない場合は，Googleドキュメントの見出しスタイルに基づく目次を挿入する。ブックマークアイコンを避ける方針の場合は，見出し横にアイコンが出ないことも確認する。
