# Markdown記述ガイドライン

本書は、Markdownで文書を書くときの改行、空行、表、リンクの記述方法を定めます。

## 段落と改行

本文の中で文を区切るときは、単一の改行ではなく、空行を挟んだ改行2回で区切ります。
Markdownは連続した行を1つの段落としてまとめるため、単一の改行では文が前の文につながって表示されます。

1つの文は途中で改行せず、文の終わりまでを1行で書きます。
行の幅をそろえるための折り返しも入れません。

## ブロックの前後の空行

表、コードブロック、箇条書きリストの前後には、1行の空行を挟みます。
空行がないと、直前や直後の段落と一続きの本文として解釈され、ブロックが表や一覧として描画されません。

## 表の記述

セルの中で改行するときは、単一の改行ではなく `<br>` タグを使います。
表は1行で1レコードを表す構造のため、セルの途中で改行すると行の区切りが崩れ、表として認識されなくなります。

セルの中で項目を並べるときも、`-` による箇条書きは使わず `<br>` で区切ります。
箇条書きはブロック要素であり、セルの中には置けないためです。

セルの中に `|` を書くときは、`\|` とエスケープします。
リンクのタイトルに含まれる `|` も同じくエスケープします。

## リンクの記述

リンクは `[<ページタイトル>](<URL>)` の形式で記載します。

ページタイトルは、参照先のページの `<title>` タグの内容をそのまま使います。

## アンカーの記述

見出しは、見出しの文字列から自動で生成されるアンカーを参照先として使います。
文書内の見出しへのリンクは `[7章](#7-引用参照)` のように、生成されたアンカーを `#` に続けて書きます。

表と図には自動でアンカーが付かないため、表題の行の先頭に `<a id="table-1"></a>` や `<a id="figure-1"></a>` を置き、そのIDへリンクします。
IDは、表では `table-` に、図では `figure-` に、それぞれの番号を続けた文字列にします。
