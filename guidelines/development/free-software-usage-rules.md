## 1 はじめに

### 1.1 目的

この文書の目的は，ライセンス違反及び脆弱性による損害を防ぐため，開発に携わる者が使用してよいフリーソフトを明確にすることである。

### 1.2 適用範囲

この文書は，開発で使用するフリーソフトの選定基準，並びに使用を許可するフリーソフト及び使用を禁止するフリーソフトについて規定する。

## 2 選定基準

使用を許可するフリーソフトは，[表1](#table-1)の基準を全て満たさなければならない。

<a id="table-1"></a>表1−フリーソフトの選定基準

| 基準 | 内容 |
| --- | --- |
| 個人利用 | 個人利用が無料である。 |
| 商用利用 | 商用利用が無料である。 |
| 脆弱性への対応 | 重大な脆弱性が修正されずに放置されていない。 |

## 3 一覧の記載方法

ライセンスの列には，ライセンスの名称を記載する。

ライセンスの条文を掲載したURLがある場合は，ライセンスの名称を，そのURLへのリンクとして記載する。
