<a id="table-10"></a>表10−テストタイプ

| テストタイプ | 説明（参考） |
| --- | --- |
| 機能テスト | テスト対象のソフトウェア又はアプリケーションの“機能”が期待どおりの結果を返すか確認するテスト |
| シナリオテスト | 利用者の実際の利用手順に沿って操作を行い<br>問題なく利用できるか確認するテスト |
| 性能テスト | ソフトウェアの処理時間などのパフォーマンスを測定するテスト |
| ロードテスト | ソフトウェアを<br>様々な状況で動作させて<br>期待どおりの結果を返すか確認するテスト |
| ストレステスト | ソフトウェアが要件で定義される限界、又はそれ以上の負荷を与えて動作を確認するテスト |
| ユーザビリティテスト | ソフトウェアが、ユーザーにとって理解されやすく、使用が容易で、魅力的であるかどうかを確認するテスト |
| ローカライゼーションテスト | 異なる言語を使用してアプリケーションに変換されたときにソフトウェアが機能することを確認するためのテスト |
| 保守性テスト | ソフトウェアに欠陥があった場合の修正の容易さ、新しい機能の追加の容易さなどを確認するテスト |
| 信頼性テスト | ソフトウェアが要件で定めた回数、期間、条件などで稼働できるかを確認するテスト（大容量テスト、エージングテストなど） |
| 移植性テスト | 将来的に、ソフトウェアを別のハードウェア又は環境に移す場合の移植の容易さを確認するテスト |
