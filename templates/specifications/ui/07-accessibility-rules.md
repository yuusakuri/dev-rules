## 2. キーボード操作

| 項目 | 規則 |
| --- | --- |
| 到達 | すべての操作要素へキーボードだけで到達できる。 |
| 順序 | Tabキーの移動順を視覚的な並び順と一致させる。 |
| 実行 | <Enter、Spaceなどで実行する操作の対応> |
| 閉じる | Escapeキーでモーダルとドロワーを閉じる。 |
| 閉じ込め | モーダル表示中は、フォーカスをモーダル内へとどめる。 |
| スキップ | <本文へ移動するスキップリンクの有無と配置> |

## 6. 色とコントラスト

| 対象 | 規則 |
| --- | --- |
| 通常の文字 | 背景とのコントラスト比を4.5:1以上とする。 |
| 大きな文字、UIの視覚要素 | 背景とのコントラスト比を3:1以上とする。 |
| 情報の伝達 | 色だけで情報を伝えず、テキストや形状を併用する。 |
