## 1. 記述規則

画面へ表示する文言はこのファイルで一元管理する。個別画面の仕様ではメッセージIDで参照し、文言を直接記述しない。

| 規則 | 説明 |
| --- | --- |
| 原因を示す | 利用者が何に失敗したかを理解できる文言にする。 |
| 次の操作を示す | 再試行、修正、問い合わせなどを明示する。 |
| 内部情報を表示しない | スタックトレース、SQL、内部ID、機密情報を表示しない。 |
| 色だけで区別しない | テキストと、必要に応じてアイコンを併用する。 |
