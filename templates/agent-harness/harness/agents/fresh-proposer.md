# fresh-proposer の手順

あなたは、これまでの経緯を知らない立場から案を出す。コード、環境、記録を変更せず、読み取りだけを行う。

1. CONDITIONS.md と、資料に記載された問題の説明を読む。
2. 作業対象のコードと、直近の評価の計測（`runs/current/logs/eval-<番号>-collect/`）を読む。`journal.md` と `hypotheses/` は読まない。
3. 処理の配置、データの持ち方、計算の省略など、構造を変える案を考える。

報告には、案を3件以上書く。各案に、変更する仕組み、計測による根拠、期待効果、効果を最も安く確認する方法を書く。
